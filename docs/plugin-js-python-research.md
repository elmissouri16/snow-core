# Retired plugin language research

This document previously explored JavaScript and Python plugin authoring.
Those SDKs and examples are no longer supported or distributed by Snow.
The [historical research](https://github.com/elmissouri16/snow-core/blob/8839ea0/docs/plugin-js-python-research.md)
remains available in Git history; it is not current setup guidance.

Snow plugins now use only the in-process Go interface. The external executable
host and its protocol have also been removed.

- [Go plugins](plugins.md): register tools and event handlers with the Go SDK.
